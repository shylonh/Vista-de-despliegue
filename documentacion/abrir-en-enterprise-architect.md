# Abrir y revisar en Enterprise Architect 15

1. En GitHub abre `diagramas/UAM-LINK-Despliegue.feap` y descarga el archivo binario mediante **Download raw file**. Descargar la página HTML de GitHub no descarga el proyecto.
2. Abre Enterprise Architect 15 y utiliza **Open Project** para seleccionar el `.feap` descargado.
3. En el navegador del proyecto busca **UAM LINK - Despliegue**.
4. Abre **01 - Arquitectura objetivo propuesta** para la vista principal.
5. Abre **02 - Prototipo actual** para contrastar la implementación disponible.
6. Revisa las propiedades de nodos, entornos, componentes y artefactos. Las notas documentan su alcance.
7. Comprueba el formato y la ubicación de las etiquetas en tu instalación de EA. El modelo fue construido y validado en su base FEAP, pero no se abrió en EA 15 dentro de este entorno.
8. Si el docente exige una exportación realizada desde EA, usa la opción de guardar imagen del diagrama o imprime el diagrama a PDF en tu instalación. Los PDF/PNG incluidos son representaciones de la misma definición, generadas fuera de EA.
9. Guarda los ajustes y reemplaza el FEAP en el repositorio mediante **Add file → Upload files**, conservando el mismo nombre.

El FEAP es un archivo de proyecto Firebird, no un XMI o XML renombrado. Cierra EA antes de subirlo para evitar copiar un archivo en uso.
